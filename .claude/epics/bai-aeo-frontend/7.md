# Task: Build single-page results dashboard

## Description
Create the results view that displays after a single-page scan completes. Includes a score gauge (0-100 with letter grade), 5 check cards (pass/fail with details), and a prioritized recommendations list. This is the core value delivery — what the user sees after scanning.

## Acceptance Criteria
- [ ] ScoreGauge component shows overall score (0-100) with letter grade (A-F)
- [ ] Score gauge is color-coded: A=green, B=blue, C=yellow, D=orange, F=red
- [ ] 5 CheckCard components: Heading Hierarchy, Meta Description, Schema Markup, FAQ Section, Content Structure
- [ ] Each CheckCard shows: pass/fail icon, score out of 20, summary message, expandable details
- [ ] RecommendationList shows prioritized actions with impact/effort badges
- [ ] "Scan Another" button resets to the form
- [ ] Layout works on mobile (cards stack vertically)

## Technical Details
- `components/ScoreGauge.tsx` — circular/arc gauge, accepts `score` and `grade` props
- `components/CheckCard.tsx` — reusable card, accepts check result object from API
- `components/RecommendationList.tsx` — ordered list of recommendation objects
- All data comes from the scan result already in reducer state (no additional API calls)
- Use Tailwind for all styling — no component library
