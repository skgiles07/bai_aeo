# Task: Build site-wide aggregate results view

## Description
Create the SiteResults component that displays after a multi-page scan completes. Shows the aggregate site score, site-wide issues summary (which checks fail across the most pages), and a per-page accordion for drill-down into individual page results. Reuses CheckCard and ScoreGauge from task 003.

## Acceptance Criteria
- [ ] Aggregate score gauge shows site-wide average score and grade
- [ ] Stats bar: total pages scanned, successful, failed
- [ ] Site issues summary: checks ranked by percentage of pages failing, with affected page count
- [ ] Per-page accordion: expandable rows showing URL + score, expanding to full CheckCard results
- [ ] Recommendations based on site-wide aggregated data
- [ ] Works on mobile (accordion is touch-friendly)

## Technical Details
- `components/SiteResults.tsx` — aggregate view container
- `components/PageAccordion.tsx` — expandable per-page results
- Reuse `ScoreGauge`, `CheckCard`, `RecommendationList` from task 003
- Data comes from the `complete` SSE event which includes `aggregateResults` object
- Site issues map to the `siteIssues` array from the API response

## Dependencies
- [ ] Task 003 (ScoreGauge, CheckCard, RecommendationList components)
- [ ] Task 004 (SSE client delivering site-wide results)
