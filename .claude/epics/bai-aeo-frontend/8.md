# Task: Add SSE client for site-wide scans with progress UI

## Description
Implement the EventSource SSE client that connects to `/api/scan-site` for multi-page scans. Build the ScanProgress component that shows real-time updates: discovery phase, per-page progress bar, live URL being scanned with individual scores. Extend the reducer to handle SSE event types.

## Acceptance Criteria
- [ ] EventSource connects to `/api/scan-site` when "Full Site" scan is submitted
- [ ] Reducer handles SSE events: `started`, `discovered`, `progress`, `complete`, `error`
- [ ] ScanProgress shows discovery status (sitemap vs link crawling, page count)
- [ ] Progress bar updates per-page (e.g., "Scanning 3 of 12...")
- [ ] Live feed of URLs being scanned with individual pass/fail scores
- [ ] Graceful handling: connection drops, timeouts, abort (user navigates away)
- [ ] EventSource cleaned up on unmount (no memory leaks)

## Technical Details
- `hooks/useSiteScan.ts` — custom hook wrapping EventSource + dispatch to reducer
- `components/ScanProgress.tsx` — progress bar, discovery status, live URL feed
- SSE endpoint: `POST /api/scan-site` (proxied through Next.js rewrite)
- Note: EventSource only supports GET. For POST with SSE, use `fetch()` with `ReadableStream` reader instead.
- Parse SSE lines manually: split on `data: `, JSON.parse each line
- Add reducer actions: `DISCOVERY_UPDATE`, `PAGE_PROGRESS`, `SITE_COMPLETE`, `SITE_ERROR`
