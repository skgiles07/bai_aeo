# Task: Build ScanForm component with URL input and scan type toggle

## Description
Create the main scanner input form. URL text field with client-side validation, a toggle to switch between single-page and site-wide scan, and a submit button that calls the appropriate API endpoint. Wire up the `useReducer` scan state machine (idle/scanning/complete/error) at the page level.

## Acceptance Criteria
- [ ] URL input field with placeholder text and auto-prepend `https://`
- [ ] Client-side URL validation (show inline error for invalid URLs)
- [ ] Toggle between "Single Page" and "Full Site" scan modes
- [ ] Submit button with loading/disabled state during scan
- [ ] Single-page scan calls `POST /api/scan` and receives JSON result
- [ ] Scan state machine (`useReducer`) manages view transitions: idle → scanning → complete/error
- [ ] Error states display user-friendly messages (unreachable, timeout, blocked)
- [ ] Works on mobile (375px width)

## Technical Details
- `app/page.tsx` — main page with `useReducer` for scan state
- `components/ScanForm.tsx` — form UI (client component with `"use client"`)
- State machine actions: `START_SCAN`, `SCAN_COMPLETE`, `SCAN_ERROR`, `RESET`
- Single-page scan: `fetch('/api/scan', { method: 'POST', body: { url } })`
- Store scan results in reducer state for the results view to consume
